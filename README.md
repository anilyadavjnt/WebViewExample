# WebViewExample 📱

A simple iOS application built using **Swift and UIKit** to demonstrate how to integrate and use `WKWebView` in an iOS app.

## 📱 Screenshots



## 🚀 Features

- Display websites inside an iOS application.
- WKWebView integration using UIKit.
- Load web pages using URL.
- Simple and clean UI.
- Native iOS WebView implementation.

## 🛠 Technologies Used

- Swift
- UIKit
- WKWebView
- Xcode

## 📚 What I Learned

- How to implement WKWebView.
- How to load URLs in an iOS application.
- How to integrate web content into a native iOS app.
